# Gami Wallet — App Store Screenshot Design Spec

## Goal
Create App Store screenshots that clearly show Gami Wallet as a rewards identity wallet for XP, quests, and onchain rewards.

## Brand Direction
- Background: deep black / purple gradient
- Primary: #7C3AED
- Secondary: #A78BFA
- Accent: #4ADE80
- Text: white and lavender
- Style: premium Web3 wallet, clean, high-contrast, app-store ready

## Screenshot Set

### 1. Home XP Dashboard
Headline: Your rewards identity
Subtext: Track XP, levels, points, and progress across Gami-powered apps.
Screen content:
- XP ring
- Level / tier card
- Universal points balance
- Recent activity

### 2. Wallet Connection
Headline: Connect securely
Subtext: Use WalletConnect and Sign-In with Ethereum to access your Gami profile.
Screen content:
- Connect wallet card
- SIWE login state
- Network card showing Gami L2

### 3. Quest Feed
Headline: Complete quests
Subtext: Earn XP from daily, weekly, sponsored, and partner campaigns.
Screen content:
- Quest cards
- Progress bars
- XP and points rewards

### 4. Reward Reveal
Headline: Unlock rewards
Subtext: Claim dynamic XP, points, boosts, badges, and partner rewards.
Screen content:
- Reward reveal modal
- +XP / +Points display
- Celebration animation

### 5. Profile + Tiers
Headline: Level up your status
Subtext: Build streaks, earn badges, and unlock higher staking tiers.
Screen content:
- Profile avatar / wallet address
- Bronze/Silver/Gold/Diamond tier
- Badge row

## Layout Rules
- Keep headline in top 20% of the screenshot.
- Device mockup should occupy 65–75% height.
- Use large readable text for App Store preview.
- Avoid mentioning guaranteed token profit.
- Use “rewards”, “XP”, “quests”, and “points” language.
