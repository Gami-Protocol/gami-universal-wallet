# Gami Protocol — TestFlight + TGE Growth Strategy

## Goal
Turn TestFlight users into early Gami community members, product testers, XP earners, and future airdrop participants.

## TestFlight Funnel

1. Invite users from X, Telegram, Discord, ETH events, and partner communities.
2. Users install Gami Wallet through TestFlight.
3. User connects wallet and completes SIWE login.
4. User completes first quest.
5. User earns XP and universal points.
6. User joins community and reports feedback.
7. User receives boosted airdrop eligibility for meaningful testing.

## Airdrop Points Model

- Wallet connect: 50 XP
- SIWE login: 100 XP
- First quest: 150 XP
- Feedback submitted: 250 XP
- Referral: 300 XP
- Extension connected: 400 XP
- Valid partner test: 500 XP
