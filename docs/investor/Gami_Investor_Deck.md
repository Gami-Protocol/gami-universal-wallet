# Gami Protocol — Investor Deck

Gami is a universal on-chain engagement engine that turns user behavior into programmable rewards using AI and blockchain.

Web3 has tokens, but no real engagement.

- Wallet identity (SIWE)
- Behavior tracking (extension)
- XP engine
- AI reward engine
- Token layer
